KEY ALGORITHM: flatten() Recursive Logic
=========================================

function flatten(tbl)
  result = []
  
  for each (key, value) in tbl:
    if value is table:
      // Recursive case (nested table)
      nested_result = flatten(value)  // Recurse
      for each nested_item in nested_result:
        result.append(key + ":" + nested_item)  // Prepend key
    else:
      // Base case (scalar value)
      result.append(key + "=" + value)
  
  return result

Example Execution:
------------------
Input: { A = { B = { C = true } } }

Step 1: Process A (table)
  - Recurse into { B = { C = true } }
  
  Step 2: Process B (table)
    - Recurse into { C = true }
    
    Step 3: Process C (scalar)
      - Return: "C=true"
    
    - Prepend B: "B:C=true"
    - Return: ["B:C=true"]
  
  - Prepend A: "A:B:C=true"
  - Return: ["A:B:C=true"]

Output: ["A:B:C=true"]
