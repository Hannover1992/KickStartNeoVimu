KEY FINDINGS SUMMARY
====================

1. WHAT ARE ROSLYN ANALYZERS?
   - Code analysis tools built on .NET Compiler Platform
   - Run during IDE editing and/or build time
   - Three categories: IDE rules (style), CA rules (quality), SA rules (StyleCop)
   - Automatically discovered via reflection from NuGet packages

2. HOW DO THEY WORK?
   - Compiler creates syntax trees and semantic model
   - Analyzer discovery via reflection
   - Analyzer initialization (register action callbacks)
   - Action execution (traverse AST, check patterns)
   - Diagnostic reporting (violations found)
   - LSP delivery to editor

3. WHY DON'T STYLECOP WARNINGS SHOW?
   - Most Common Cause: RoslynExtensionsOptions:EnableAnalyzersSupport = false
   - Solution: Set to true in omnisharp.json or command-line args
   - Must verify in process arguments: ps aux | grep omnisharp

4. HOW TO CONFIGURE?
   - EditorConfig (precedence 4): dotnet_diagnostic.SA1116.severity = warning
   - Ruleset files (precedence 5): <Rule Id="SA1116" Action="Warning" />
   - omnisharp.json (precedence 3): RoslynExtensionsOptions settings
   - Project file (precedence 6): MSBuild properties
   - Command-line (precedence 1): Overrides everything

5. HOW STYLECOP INTEGRATES?
   - Install via NuGet: StyleCop.Analyzers package
   - Automatically discovered by compiler
   - Provides DiagnosticAnalyzer implementations (SA rules)
   - Configured via .editorconfig or .ruleset
   - Integrated into build and IDE automatically

6. IDE/LSP INTEGRATION?
   - OmniSharp loads analyzers from project
   - Runs them on current document
   - Sends diagnostics via textDocument/publishDiagnostics (LSP)
   - Editor displays squiggles, error list, code fixes
   - All automatic once RoslynExtensionsOptions:EnableAnalyzersSupport=true

CRITICAL CONFIGURATION FOR OMNISHARP
=====================================

File: omnisharp.json
Location: ~/.omnisharp/ or /project/omnisharp.json

Content:
{
  "RoslynExtensionsOptions": {
    "EnableAnalyzersSupport": true,        <--- CRITICAL FOR STYLECOP!
    "EnableImportCompletion": true,
    "AnalyzeOpenDocumentsOnly": false
  },
  "FormattingOptions": {
    "EnableEditorConfigSupport": true,
    "OrganizeImports": true
  }
}

Command-line equivalent:
dotnet /path/to/OmniSharp.dll -s /path/to/solution \
  RoslynExtensionsOptions:EnableAnalyzersSupport=true \
  RoslynExtensionsOptions:AnalyzeOpenDocumentsOnly=false

Verification:
ps aux | grep omnisharp | grep -v grep
# Should show: RoslynExtensionsOptions:EnableAnalyzersSupport=true

ANALYZER API SURFACE (Quick Reference)
=======================================

DiagnosticAnalyzer (abstract base class)
├─ public abstract void Initialize(AnalysisContext context)
└─ public abstract ImmutableArray<DiagnosticDescriptor> SupportedDiagnostics

AnalysisContext (for registering actions)
├─ void RegisterSyntaxNodeAction<T>(Action<SyntaxNodeAnalysisContext> action, ...)
├─ void RegisterSymbolAction(Action<SymbolAnalysisContext> action, ...)
├─ void RegisterSemanticModelAction(Action<SemanticModelAnalysisContext> action)
├─ void RegisterCodeBlockStartAction<T>(Action<CodeBlockStartAnalysisContext<T>> action)
├─ void RegisterCompilationStartAction(Action<CompilationStartAnalysisContext> action)
├─ void RegisterCompilationEndAction(Action<CompilationAnalysisContext> action)
└─ void EnableConcurrentExecution()

Diagnostic (reported result)
├─ DiagnosticDescriptor Descriptor
├─ Location Location
├─ DiagnosticSeverity Severity
├─ string Message
└─ ImmutableDictionary<string, string?> Properties

DiagnosticSeverity (enum)
├─ Hidden (0)
├─ Info (1)
├─ Warning (2)
└─ Error (3)

---

ANALYZER ACTION EXECUTION ORDER GUARANTEE
==========================================

Compilation Start
  └─ Symbol Start
      ├─ Symbol Actions
      ├─ Semantic Model Actions
      ├─ Code Block Start
      │  ├─ Syntax Node Actions
      │  └─ Code Block End
      └─ Symbol End
Compilation End

Key Guarantee:
- Within each category: Start actions BEFORE End actions
- No guaranteed order between different action types
- Enables safe parallelization

ANALYZER CONFIGURATION HIERARCHY (Precedence)
==============================================

1. Command-Line Arguments (Highest - overrides everything)
2. Environment Variables
3. omnisharp.json (project or global)
4. .editorconfig files
5. .ruleset files
6. .csproj properties
7. Analyzer Defaults (Lowest)

MOST IMPORTANT FOR OMNISHARP/NEOVIM USERS
==========================================

To enable StyleCop warnings in OmniSharp/Neovim:

1. Ensure StyleCop.Analyzers is installed in .csproj:
   <PackageReference Include="StyleCop.Analyzers" Version="1.1.118" />

2. Configure omnisharp.json:
   {
     "RoslynExtensionsOptions": {
       "EnableAnalyzersSupport": true,
       "AnalyzeOpenDocumentsOnly": false
     }
   }

3. Create .editorconfig with StyleCop rules:
   dotnet_diagnostic.SA1116.severity = warning
   dotnet_diagnostic.SA1117.severity = warning

4. Verify process:
   ps aux | grep omnisharp
   # Should show: RoslynExtensionsOptions:EnableAnalyzersSupport=true

5. Check in editor:
   :LspInfo  # Should show RoslynExtensionsOptions in config
