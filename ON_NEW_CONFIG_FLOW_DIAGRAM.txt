SCENARIO 1: User Provides Custom cmd (CORRECT)
================================================================================

User Configuration (init.lua):
┌─────────────────────────────────────────────────────────────────┐
│ local servers = {                                               │
│   omnisharp = {                                                │
│     cmd = {                                                    │
│       'dotnet',                                               │
│       '/home/user/.../OmniSharp.dll',                         │
│       '-s', '/path/to/Backend',                              │
│       '-loglevel', 'Information',                            │
│     },                                                         │
│     settings = {                                              │
│       RoslynExtensionsOptions = {                            │
│         EnableAnalyzersSupport = true,                       │
│       }                                                        │
│     }                                                          │
│   }                                                            │
│ }                                                              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                  lspconfig reads this config
                              ↓
              Default config merged with user config
              (user config WINS for cmd field)
                              ↓
        new_config.cmd = user's custom cmd (7 elements)
        new_config.settings = user's settings (nested)
                              ↓
         ╔═══════════════════════════════════════════════╗
         ║         on_new_config() CALLED                ║
         ║  (when LSP attaches to C# file)              ║
         ╚═══════════════════════════════════════════════╝
                              ↓
         ┌──────────────────────────────────────┐
         │ STEP 1: Copy cmd (ensure it's array) │
         └──────────────────────────────────────┘
         new_config.cmd = { unpack(new_config.cmd or {}) }

         BEFORE: { 'dotnet', '/path/to/OmniSharp.dll', '-s', '/path/to/Backend',
                   '-loglevel', 'Information' }
         AFTER:  { 'dotnet', '/path/to/OmniSharp.dll', '-s', '/path/to/Backend',
                   '-loglevel', 'Information' }  (same)
                              ↓
         ┌──────────────────────────────────────┐
         │ STEP 2: Append hard-coded LSP args   │
         └──────────────────────────────────────┘
         table.insert(new_config.cmd, '-z')
         vim.list_extend(new_config.cmd, { '--hostPID', tostring(12345) })
         table.insert(new_config.cmd, 'DotNet:enablePackageRestore=false')
         vim.list_extend(new_config.cmd, { '--encoding', 'utf-8' })
         table.insert(new_config.cmd, '--languageserver')

         RESULT:
         { 'dotnet', '/path/to/OmniSharp.dll', '-s', '/path/to/Backend',
           '-loglevel', 'Information', '-z', '--hostPID', '12345',
           'DotNet:enablePackageRestore=false', '--encoding', 'utf-8',
           '--languageserver' }  (12 elements now)
                              ↓
         ┌──────────────────────────────────────┐
         │ STEP 3: Flatten settings to cmd      │
         └──────────────────────────────────────┘
         flatten(RoslynExtensionsOptions = { EnableAnalyzersSupport = true })
         → produces: "RoslynExtensionsOptions:EnableAnalyzersSupport=true"

         vim.list_extend(new_config.cmd, flattened_settings)

         RESULT:
         { 'dotnet', '/path/to/OmniSharp.dll', '-s', '/path/to/Backend',
           '-loglevel', 'Information', '-z', '--hostPID', '12345',
           'DotNet:enablePackageRestore=false', '--encoding', 'utf-8',
           '--languageserver', 'RoslynExtensionsOptions:EnableAnalyzersSupport=true' }
                              ↓
         ┌──────────────────────────────────────┐
         │ STEP 4: Disable unsupported caps     │
         └──────────────────────────────────────┘
         new_config.capabilities.workspace.workspaceFolders = false
                              ↓
                  Final cmd array ready
                              ↓
                  vim.fn.jobstart(final_cmd)
                              ↓
         ┌──────────────────────────────────────┐
         │  OmniSharp Process Spawned With:     │
         │  dotnet /path/to/OmniSharp.dll       │
         │    -s /path/to/Backend               │
         │    -loglevel Information             │
         │    -z --hostPID 12345                │
         │    DotNet:enablePackageRestore=false │
         │    --encoding utf-8 --languageserver │
         │    RoslynExtensionsOptions:...=true  │
         └──────────────────────────────────────┘
                              ✅
                      All settings applied!

SCENARIO 4: Mason Installing OmniSharp (HOW IT FITS)
================================================================================

Mason Installation Process:
┌─────────────────────────────────────────────────────────────┐
│ 1. User runs: :Mason                                        │
│ 2. Find "omnisharp" package                                │
│ 3. Press 'i' to install                                    │
│ 4. Mason downloads from GitHub releases                    │
│ 5. Extracts to: ~/.local/share/nvim/mason/packages/omnisharp/
│                                                             │
│ Result directory structure:                                │
│ ~/.local/share/nvim/mason/                                │
│ ├── bin/                                                   │
│ │   └── OmniSharp → ../packages/omnisharp/bin/OmniSharp   │
│ └── packages/                                             │
│     └── omnisharp/                                       │
│         ├── libexec/OmniSharp.dll  ← Actual executable   │
│         └── bin/OmniSharp           ← Wrapper script    │
└─────────────────────────────────────────────────────────────┘
                              ↓
      Mason adds ~/.local/share/nvim/mason/bin/ to PATH
                              ↓
         Now "OmniSharp" is findable in PATH
                              ↓
         ╔═══════════════════════════════════════════════╗
         ║   But Mason does NOT:                         ║
         ║   - Override user's cmd configuration         ║
         ║   - Inject wrapper scripts with settings      ║
         ║   - Modify on_new_config function            ║
         ║                                               ║
         ║   Mason ONLY:                                 ║
         ║   - Installs binary                           ║
         ║   - Makes it findable in PATH                 ║
         ╚═══════════════════════════════════════════════╝
                              ↓
      User Config Still Controls Everything
      (cmd, settings, on_new_config behavior)


CONFIG MERGE ORDER
================================================================================

Priority (highest to lowest):

1. Explicit omnisharp.setup() call   ← User's explicit setup() has highest priority
2. User-defined servers.omnisharp    ← If user provides config table
3. mason-lspconfig handler           ← Default handler if omnisharp in servers
4. default_config from omnisharp.lua ← Fallback default config

Example:

┌─────────────────────────────────────────────────────────────┐
│ if servers.omnisharp then   ← Check this first           │
│   -- Priority 2: Use this if present                       │
│ else                                                        │
│   -- Priority 3: Use handler default                       │
│   -- Priority 4: Use omnisharp.lua default_config          │
│ end                                                         │
└─────────────────────────────────────────────────────────────┘


CRITICAL ISSUE: SCOPE PROBLEM IN CLAUDE.md
================================================================================

The documented issue was:

```lua
local servers = {  ← Local scope starts here
  omnisharp = { cmd = {...}, settings = {...} }
}

require('mason-lspconfig').setup {
  handlers = {
    function(server_name)
      local server = servers[server_name]  ← servers IN SCOPE here ✅
      require('lspconfig')[server_name].setup(server)
    end,
  },
}
                    ← Local scope ends here

-- If omnisharp setup attempted outside local scope:
if servers.omnisharp then  ← servers NOT IN SCOPE here ❌
  -- This won't work!
end
```

Solution: Perform omnisharp setup inside the local scope.
