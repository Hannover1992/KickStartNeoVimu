================================================================================
                              HOW TO USE
================================================================================

Option 1: Command Mode
  :map <leader>r
  Shows all <leader>r keybindings with their descriptions

Option 2: Telescope Search
  :Telescope keymaps
  Search for "dotnet", "docker", "npm", "git" to find related commands

Option 3: Leader Key Help
  <leader>?
  Shows all keybindings in a nice menu (with which-key plugin)

Option 4: In Insert Mode
  Press <leader> in insert mode - typically shows a popup with hints

================================================================================
                            TROUBLESHOOTING
================================================================================

Keybindings not appearing?
  1. Restart Neovim completely
  2. Check file saved: :edit ~/.config/nvim/init.lua
  3. Verify changes: :checkhealth

Want to search for specific command?
  :Telescope keymaps
  Type the command or part of it (e.g., "dotnet", "docker")

Want to see all keybindings?
  :map                 " All mappings
  :map <leader>r       " Just backend/run mappings
  :map <leader>R       " Just capitalized leader mappings

Customize descriptions?
  Edit init.lua, find the keybinding, change the { desc = '...' } part

================================================================================
                              KEYBOARD TIPS
================================================================================

<leader> key binding:
  The <leader> key is typically:
  - Space in this config (set leader = ' ')
  - Can also be comma (,) or backslash (\) depending on your setup

Examples:
  <leader>rbw  means: Press Space, then 'r', then 'b', then 'w'
  <leader>rp   means: Press Space, then 'r', then 'p'

Faster entry:
  You can type these all at once! No need for pauses between keys.
  Just type: Space + r + b + w  and it will trigger <leader>rbw
